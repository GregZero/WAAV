💬 Aide — WAAV

📂 Importer des archives

Exportez depuis WhatsApp : Paramètres → Discussions → Exporter, sans médias → fichier .txt.
Formats acceptés : .txt (WhatsApp) et .json (export WAAV).
Glissez les fichiers sur la zone de droite ou utilisez le bouton Importer.
Importez plusieurs exports à la suite pour les fusionner — les doublons sont détectés automatiquement.
Chaque archive apparaît dans la liste avec son nombre de messages. Cliquez ✕ pour en retirer une.

🔍 Recherche

Tapez un mot-clé puis appuyez sur Entrée ou cliquez ailleurs pour lancer.
Les résultats sont surlignés en jaune — seuls les jours contenant des résultats sont dépliés.
Si la recherche donne beaucoup de résultats, une confirmation est demandée avant l'affichage : 🟡 au-delà de 1 000 (un peu long), 🔴 au-delà de 5 000 (très long). Ces seuils se règlent dans ⚙ Réglages (icône engrenage à côté du titre) — 0 = désactivé.
Appuyez sur Échap ou cliquez sur le bouton ✕ du champ pour effacer la recherche et revenir à la vue normale.

📅 Période & Empilement

Le sélecteur Période filtre par année ou par mois. Tous les messages réaffiche tout.
Le sélecteur Empiler par regroupe les messages par Mois (par défaut), Jour ou Année — s'applique immédiatement. La valeur au démarrage se règle dans ⚙ Réglages.
Le bouton ▾ Empiler replie ou déplie tous les groupes du niveau actif d'un seul coup.
Un bouton ↑ replier apparaît en bas de chaque groupe ouvert pour le refermer après lecture.
Cliquez sur un séparateur de jour, mois ou année pour le replier/déplier individuellement.

👥 Participants

Cliquez sur un participant dans le panneau gauche pour changer le côté d'affichage de ses bulles :
Nom dot à gauche → bulles à droite
Nom dot à droite → bulles à gauche
Nom estompé → participant masqué

⚠️ Doublons

Les messages communs entre archives sont détectés et encadrés en orange.
🟠 Masquer — désactive le marquage orange sans rien supprimer.
🗑 Supprimer les doublons — supprime les copies, conserve la première occurrence.

📤 Exports

JSON — tableau d'objets avec toutes les métadonnées, réimportable dans WAAV.
TXT — format WhatsApp original, réimportable dans WAAV ou lisible dans tout éditeur.
SQLite — base de données .db, ouvrable avec DB Browser for SQLite.
MySQL — fichier .sql importable directement dans phpMyAdmin (utf8mb4).
Tous les exports respectent la période et les filtres actifs au moment de l'export.

📱 Panneau gauche & Mobile

Le bouton ☰ dans le header masque ou affiche le panneau gauche.
Sur mobile, le panneau s'ouvre en tiroir. Tapez en dehors pour le refermer.

💾 Données & Confidentialité

Toutes les données restent sur votre appareil — aucun serveur, aucun réseau. Fonctionne hors ligne.
Les archives sont stockées dans IndexedDB et rechargées automatiquement à la prochaine ouverture.
À l'ouverture, WAAV détecte les anciennes bases obsolètes (versions 1.0 à 1.7) et vous propose de les supprimer — jamais automatiquement. Vos archives (base wa_archive) ne sont jamais touchées. Voir ⚙ Réglages pour l'état et la suppression, ainsi que l'emplacement du stockage.
Pour tout effacer : bouton Effacer dans le panneau gauche, ou F12 → Stockage → Base de données indexée → wa_archive.

⚙ Réglages — WAAV

🔍 Recherche — seuils d'avertissement

Nombre de messages trouvés au-delà duquel une confirmation est demandée avant l'affichage. 0 = désactivé. Les réglages sont enregistrés automatiquement.

📚 Affichage — empiler par défaut

⚠️ Plus le regroupement est fin, plus l'affichage est lourd. « Jour » crée beaucoup de groupes et « Aucun » affiche tous les messages dépliés : cela peut devenir très lent, voire figer le navigateur, sur de gros volumes (plusieurs dizaines de milliers de messages). « Mois » est le meilleur compromis.
Le sélecteur « Empiler par » du panneau gauche reste utilisable pour changer temporairement ; ce réglage définit la valeur au démarrage.

🗂 Données — anciennes bases

Détection à l'ouverture de WAAV ; rien n'est supprimé sans votre confirmation. 🔒 Jamais concernés : vos archives actuelles (wa_archive, utilisée par les versions 1.8 à 1.9.x) et vos réglages.

📍 Stockage lié à

Un navigateur sépare les données selon le fichier/site qui les a créées. Selon le navigateur, un autre fichier HTML (autre nom ou autre dossier, par exemple une nouvelle version) peut avoir son propre stockage, invisible pour cette page : WAAV ne peut alors pas détecter ce qu'une autre version y a laissé. Pour retrouver ces données, rouvrez l'ancien fichier et utilisez Export → JSON, puis Importer ici. Conserver le même nom et le même dossier de fichier d'une version à l'autre permet en général de partager le stockage. Firefox isole chaque fichier HTML (stockage lié à son chemin complet) : une nouvelle version enregistrée sous un autre nom ne voit pas les archives de la précédente. Une solution durable : ouvrir WAAV depuis une adresse fixe (hébergement web, ou petit serveur local), car toutes les versions servies par la même adresse partagent alors le même stockage.
